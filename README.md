# Dungeon Sweeper

A dungeon-crawling game inspired by [DragonSweeper](https://danielben.itch.io/dragonsweeper) by Daniel Benmergui, where every cell hides a potential threat, treasure, or deadly trap.

Explore dangerous dungeons, uncover monsters, manage your health, collect items, and use enemies to survive. Every decision matters — one wrong move could be your last.

## 🎮 Play the Game

**[▶ Play Dungeon Sweeper](https://nadimsaba.github.io/DungeonSweeperWebGL/)**

*The game runs in your browser using Unity WebGL. No installation required.*

> Note: This is a browser-playable version of the game, provided for testing and demonstration purposes.

## 🕹️ How to Play

- **Left-click:** Reveal or interact with a cell.
- **Long Left-click:** Mark a cell to help keep track of uncertain locations (for mobile).
- **Right-click:** Mark a cell to help keep track of uncertain locations.
- **Use items:** Survive dangerous encounters and gain an advantage.
- **Read the numbers:** Use adjacent monster attack values to evaluate the danger around you.
- **Defeat the boss:** Explore the dungeon and find a way to survive.

## ✨ Features

- Minesweeper-inspired dungeon exploration.
- Turn-based combat and strategic risk management.
- Different monsters, traps, treasures, and items.
- Unique enemy mechanics and dungeon encounters.
- Pixel-art visuals and animations.
- A grimoire to discover and learn about enemies and items.

## 🛠️ Built With

- **Unity** — Game engine.
- **C#** — Gameplay programming.
- **Unity WebGL** — Browser deployment.
